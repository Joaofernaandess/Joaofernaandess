### 🚀 O que estou construindo

Em vez de focar apenas em linguagens da moda, foco na resolução de problemas. Aqui estão alguns projetos que lidero e mantenho:

- **[SommusESales](https://github.com/sommus/SommusESales-desktop):** Aplicação desktop desenvolvida em C# .NET 8 WinForms que processa arquivos DBF para automação e integração de notas fiscais e sellout.
- **[ExtractorCobol](https://github.com/Joaofernaandess/ExtractorCobol.git):** Ferramenta customizada em Windows Forms que faz o parse de arquivos fonte COBOL para extrair e executar queries SQL em bancos relacionais.
- **[Pedido Certo AI](https://github.com/zenitetecnologia/pedido-certo-ai-app):** Solução web com wizard de múltiplos passos para gestão de dossiês e busca automatizada de dados via CNPJ.
- **[Academia Certa](https://github.com/Joaofernaandess/Academia_certa):** Web app fullstack para gestão de academias, contando com montador de treinos estruturado por grupos musculares e dashboards avaliativos de equipamentos.
